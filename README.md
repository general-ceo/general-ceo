## Featured Work

**Hardware Authentication System (555 Timer and Digital Logic)** — *In progress for Intro to Computer and Network Security.* A physical authentication circuit that adds a security layer beyond passwords, which are vulnerable to guessing and repeated unauthorized attempts. The user must enter the correct sequence on push buttons or switches before a 555 timer expires; if the sequence isn't entered in time, the system denies access.

[**GameGPT**](https://github.com/diegomaldon/Team11_GameGPT) — *In progress, CIS 454 Software Implementation Project (Team 11).* A cross-platform game-discovery app: link your gaming accounts, describe a vibe in natural language, and get 3-5 ranked recommendations from a RAG pipeline over a game knowledge base, with games you already own filtered out and thumbs up/down feedback. Built as an end-to-end walking skeleton with every external dependency behind a swappable service class. Stack: Python, FastAPI, Postgres + pgvector, Hugging Face embeddings, Google Gemini, Next.js, TypeScript, Tailwind CSS.

**Academic Lens** — A 1:1 scale VR digital twin environment built with Unity and real-world spatial mapping data. Python validation scripts enforce LOD performance targets, cutting manual QA time and holding 90fps in real-time rendering.

**Track and Snack** — A full-stack MVP connecting local food vendors with customers during post-COVID recovery. Built with JavaScript, HTML/CSS, and a PostgreSQL-backed searchable database, with a UI designed for small business owners with minimal technical experience.
